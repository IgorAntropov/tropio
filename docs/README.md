# Технический справочник Трулала

Здесь описаны пользовательские сценарии, состояния интерфейса, API и события, ошибки и кейсы для проверки.

Из корня репозитория установи зависимости и собери справочник.

```sh
npm --prefix docs ci
npm --prefix docs run build
```

Открой [оглавление](index.html) в браузере. Сервер не требуется.

Для просмотра вместе с локальными материалами проекта выполни из корня репозитория:

```sh
npm --prefix docs run build:local
```

Открой файл `.local/handbook/index.html`. Локальный комплект сохраняется в `.local/handbook/`, публичный — в `docs/generated/`. Обе версии можно использовать одновременно.
